# UI/UX Pro Max Frontend Design

## Use when
- You are designing or revising a visible product UI.
- The request cares about polish, feel, or visual identity.

## Quick rules
- Pick one strong visual direction and commit to it.
- Use purposeful typography and avoid default-looking stacks.
- Build atmosphere with gradients, texture, or shape.
- Add motion only where it helps orientation or delight.
- Keep mobile and desktop equally considered.

## Guardrails
- Avoid bland purple-on-white defaults.
- Avoid generic boilerplate layouts.
- Keep accessibility, contrast, and responsive behavior intact.
