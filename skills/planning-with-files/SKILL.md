# Planning With Files

## Use when
- A task spans multiple files or multiple passes.
- You need an explicit plan, checkpoints, or handoff notes.

## Quick rules
- Write the plan where the work lives.
- Keep one slice small enough to verify on its own.
- Record assumptions, open questions, and rollback points.
- Prefer file-backed progress over chat-only progress.

## Good pattern
- Plan
- Implement slice
- Verify
- Repair
- Commit the outcome to a durable note
