# Obsidian Skills

## Use when
- You are turning work into a durable note or knowledge base entry.

## Quick rules
- Keep notes atomic and link them together.
- Use frontmatter for metadata that will matter later.
- Capture decisions, not just outcomes.
- Prefer short source notes plus one synthesized note.

## Good habits
- Add backlinks and tags only where they help retrieval.
- Keep inbox notes brief, then promote them into stable notes.
