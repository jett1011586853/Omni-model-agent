# Coding Standards

## Use when
- You are writing or reviewing code.

## Quick rules
- Keep diffs small and local.
- Do not mix unrelated cleanup into a feature change.
- Favor clear names over clever names.
- Use comments only when the code is otherwise hard to follow.
- Verify formatting, build, and tests before declaring success.

## Review mindset
- Prefer clarity over micro-optimization.
- Prefer explicit behavior over hidden conventions.
